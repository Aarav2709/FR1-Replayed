# FR1 Replayed

FR1 Replayed is a fan made revival of Fun Run 1 (v2.24.1) for mobile and PC. The game runs offline and saves progress on the device. Friends on the same network can race each other over LAN.

## Features

* Quick Play races against bots, with map voting, coins and rating
* Practice races against three bots
* LAN races with up to four friends on the same network: host a game or join one (found automatically, or by address)
* All 37 maps, the tutorial map and every power up
* Weekly and all time rankings
* Daily challenges
* The market with avatars, hats, items and boots
* Change your username in settings
* 60 FPS, with the layout scaled for any screen

LAN races use UDP port 23400 to find games and TCP port 23401 for the race. On Windows, allow the game through the firewall when asked.

## Platforms

* Android
* iOS
* PC (use the arrow keys and Enter or the mouse for menus, Escape to go back, Space to jump and X for power ups)

On PC the game opens in fullscreen with a PC main menu. Press F11 to switch between fullscreen and a window, and Escape during a race to open the race menu. In the shop, Left and Right browse items, Up and Down change the category and the mouse wheel scrolls. Settings has a PC page for fullscreen, the window size and the jump and power up keys.

## Run

Open `main.lua` in the [Solar2D](https://solar2d.com/) simulator, or build it for your platform. `PCMode.bat` opens the simulator with the PC layout and controls, and `ResetData.bat` deletes the simulator save so you can start over.
